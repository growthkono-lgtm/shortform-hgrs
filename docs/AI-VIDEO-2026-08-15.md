2026-08-15. 사장님 요청: *"대놓고 AI 영상이지만 퀄리티가 좋은 것들 / 종류별로 AI 영상을
기획제작하는 것. 결국 프롬프트와 툴을 잘 섞어 짜야 할 것 같은데, 우린 지금 어떤 걸로

## 0. 먼저 알아야 할 것 — 우리에게 마감이 있다

> **OpenAI Videos API 와 sora-2 전 모델이 2026년 9월 24일에 삭제된다. 오늘부터 40일.**

OpenAI 공시 페이지에서 직접 확인했다(2026-08-15 실측, 추측 아님):

```
2026-03-24: Sora 2 video generation models and Videos API

generation model aliases and snapshots of their deprecation and removal from the API
```

우리 계정에서 `GET /v1/videos` 는 **아직 200 을 준다.** 지난 작업분도 그대로 조회된다.
즉 지금은 되지만, **스냅샷 고정으로 버틸 수 없다** — 별칭이 아니라 스냅샷까지 전부
삭제 대상이다. 소비자용 Sora 앱은 2026-04-26 에 이미 닫혔다.

**우리 `lib/adfilm.ts` 는 sora-2 단일 의존이다.** 갈아타는 건 선택이 아니라 일정이다.

## 1. 우리가 지금 쓰는 것 (기존 스펙 정리)

코드에서 그대로 읽어 온 것이다. 감이 아니라 파일에 적힌 값이다.

| 층 | 지금 쓰는 것 | 위치 |
| --- | --- | --- |
| 영상 생성 | **OpenAI sora-2 단일**. 720×1280, 4·8·12초만 (16·20초는 API가 거부), `extensions` 로 이어 붙임 | `lib/adfilm.ts` |

**정직하게 평가하면 이렇다.**

- 잘 되어 있는 것: **기획·편집·검수 규격**. 소구 12칸, 자막 1층 실측, 나레이션 밀도
  하한, whisper 역검증 — 이건 남들이 문서로 안 갖고 있는 자산이다. 여기가 우리 강점이다.
- 비어 있는 것: **생성 층이 sora-2 하나뿐이다.** 툴을 "잘 섞어 짜는" 구조가 아니라
  한 툴에 전부 걸어 둔 구조다. 그 툴이 40일 뒤 없어진다.
- 또 비어 있는 것: **포맷이 하나뿐이다.** 실사 UGC 톤(`FILM_TONE`) 한 종류로만 만든다.
  "종류별로 기획제작" 하는 구조가 아니다.

### 한국어 — 확인됨, 단 조건이 붙는다

- Seedance 2.0: 8개 이상 언어 립싱크, **한국어 포함**. 단 *"Japanese and Korean work but
  occasionally drift on longer phrases"* — **긴 문장에서 입이 어긋난다.** 권장은 한 줄 5~10단어.
- Kling: 공식 블로그는 5개 언어(한국어 포함)라 하는데, **fal 문서에는 음성 ID가 중국어·영어만**
  적혀 있다. 경로에 따라 다를 수 있어 실측 전에는 확정 못 한다.
- 한국어 특유 함정: *"Korean has no neutral register"* — 반사적으로 격식체를 쓰면
  **존댓말 어미가 음절 예산을 잡아먹는다.** 내용이 들어갈 자리를 어미가 차지한다.

→ 우리 규격(자막 8~11자, 나레이션 8.5자/초, 해요체)이 **이미 "짧게 끊기"** 라서 이 제약과
맞는다. 레퍼런스 역산으로 뽑은 값이라 우연이 아니다.

여기서 우리에게 제일 큰 항목은 **한국어 립싱크**다. 지금 우리는 sora 로 그림을 만들고
OpenAI TTS 로 말을 얹은 뒤 ffmpeg 로 붙인다. Kling O3 는 그걸 **한 번에** 낸다.
`nova` 발음 문제로 whisper 역검증까지 만들어 붙인 그 층이 통째로 줄어들 수 있다.

⚠️ 단 검증 안 된 것: **Kling 의 한국어 립싱크가 실제로 우리 기준(구매전환 소재의
8.5자/초 속사포)을 견디는지**는 아무도 대신 답해 주지 않는다. 이건 우리가 같은 대본으로
직접 뽑아 보고 whisper 로 되받아써 봐야 안다. 우리에겐 이미 그 검증 도구가 있다.

## 4. 레퍼런스 B — "종류별로 기획제작" (CCFM 해부)

사장님이 보내신 <https://ccfm-shortform.imweb.me> 다. 운영사는 **㈜삼초마을**(강남 역삼,
대표 성주영). 사이트에서 그대로 읽어 온 구조다.

### 상품이 둘로 갈려 있다

| | 커스텀형 | **볼륨형** |
| --- | --- | --- |
| 단계 | 7단계 (질문리스트 → 맞춤포맷 제안 → 상세기획 → 확정 → 제작 → 수정 → 납품) | **5단계** |
| 컨펌 | 매 단계 | **없음 — "컨펌 없이 즉시 진행"** |
| 납기 | 한 달 이상 | **영업일 15일 내 12편** (일반 제작사 42일 대비) |
| 수정 | 피드백 반영 | **1회, 범위 제한** |

볼륨형 5단계: 제품정보 파악 → **AI 기반 기획(데이터 검증된 AI 포맷으로, 컨펌 없이 즉시)**
→ 12건 동시 제작 → 내부 퀄리티 체크 → 제작본 + **클린본** 전달.

수정 가능: 자막 스타일 · BGM · PIP 자료 · 색보정 · TTS 멘트
수정 불가: 전체 기획 변경 · 영상 컷 교체 · 인물 변경 · 제품 패키지 변경

### 핵심은 "검증된 14가지 포맷". 6개만 공개한다

| # | 포맷 | 설명 | 실사 여부 |
| --- | --- | --- | --- |
| 01 | **인물형** | 실사용 모델 인터뷰 형식 | 실사 |
| 02 | **종이콜라주형** | 아날로그 핸드메이드 무드 | 비실사 |
| 03 | **3D 원료 애니메이션형** | 원료 특징을 입체로 | 비실사 |
| 04 | **쏟아지는 제품형** | 풍성한 제품감 | 반실사 |
| 05 | **픽셀아트형** | 레트로 픽셀, 순간 시선 잡기 | 비실사 |
| 06 | **슬라임 ASMR형** | 촉각 질감으로 체류 상승 | 비실사 |

나머지 8개는 사업소개서에서만 공개한다. 타겟 업종은 **뷰티(기초·스킨케어) / 건강기능식품 /
그 외(패션·푸드·병원·생활용품)**. 사이트에 4문항짜리 자가진단이 붙어 있어 커스텀형·볼륨형으로
스스로 분류하게 만든다.

### 여기서 배울 것 — 이게 이번 조사의 제일 큰 수확이다

**공개된 6포맷 중 실사는 하나뿐이다.** 나머지는 종이·픽셀·3D·슬라임이다.
이건 미감 취향이 아니라 **전략**이다:

1. **AI 티가 문제가 안 된다.** 종이콜라주에 "실물 같지 않다"는 지적을 할 수 없다.
   우리는 지금 실사 UGC 한 종류만 만들어서, 매번 "실물처럼 보이는가"라는 가장 어려운
   싸움을 걸고 있다.
2. **편차가 안 생긴다.** 그래서 "제작 인력에 따른 편차 없이 균일한 퀄리티"를 약속할 수 있다.
3. **규제를 피해 간다** (아래 6번). 가상인물 표시의무는 실사 인물형에만 붙는다.
4. **컨펌을 없앨 수 있다.** 포맷이 정해져 있으니 기획 승인이 필요 없고, 그래서 15일에 12편이 된다.

우리 `FILM_TONE` 은 *"광고처럼 보이면 실패다 / 손에 든 스마트폰으로 찍은 듯한 미세한 흔들림"*
한 줄로 고정돼 있다. **포맷 축이 없다.**

## 6. 규제 — 우리 스펙에 지금 빠져 있다

조사 중 나온 것 중 제일 급한 항목이다. **우리 `auditAdFilm()` 에 이 검사가 없다.**

1. **AI 기본법 시행 (2026-01-22)** — 생성형 AI 기반 제품·서비스 제공자는 그 사실을
   이용자에게 사전 고지하고 **결과물에 AI 생성 사실을 표시**할 의무가 있다.
2. **공정위 「추천·보증 등에 관한 표시·광고 심사지침」 개정** (2026-04-08 행정예고) —
   추천·보증 주체에 **⑤가상인물**이 신설된다. *"인공지능 등을 기반으로 실제와 구분하기
   어려운 가상의 인물"* 을 쓴 광고는 **'가상인물'임을 표시**해야 하고, 문자·사진·영상
   매체별 표시 방법이 규정된다. 위반 시 표시광고법상 기만적 표시·광고 →
   **시정명령·과징금·형사처벌.**
3. **적용 제외**: 명백한 만화·일러스트 캐릭터 / 라이선스 보유 디지털휴먼 / 단순 보정·합성.

→ **우리가 만드는 것은 정확히 규제 대상이다.** `FILM_TONE` 이 *"손에 든 스마트폰으로
찍은 듯"* 한 실사 인물을 만들라고 지시하고 있으니 "실제와 구분하기 어려운 가상의 인물"에
그대로 해당한다. 코웨이·메디힐이 공모 요강에 *"AI 제작 사실 명확히 표기"* 를 박아 넣은

## 7. 대안 — 세 갈래

### 공통 전제
우리 강점은 **생성 툴이 아니라 기획·편집·검수 규격**이다(1번 표). 툴은 매주 바뀌고
블링크스튜디오도 같은 말을 한다. 그러니 **어느 안을 고르든 생성 층을 갈아 끼울 수 있게
떼어 내는 것**이 먼저다. 지금은 `lib/adfilm.ts` 가 sora API 를 직접 부르고 있어서,
툴을 바꾸려면 그 파일을 다시 쓰는 구조다.

### 안 1. 「갈아타기만」 — 최소 공사, 40일 안에 끝내야 하는 것
sora-2 자리에 다른 모델을 넣고 나머지는 그대로 둔다.

- 생성 층을 어댑터로 분리(sora / kling / veo 를 같은 함수로 부름)
- 후보 1순위 **Kling O3** — 한국어 립싱크 네이티브라 우리 TTS·whisper 층이 줄어든다
- 후보 2순위 **Veo 3.1 Fast**($0.10/초, 우리 현재 단가와 동일)
- 검증: **같은 대본으로 sora·kling·veo 각 1편씩 뽑아 whisper 역검증 + 우리 `auditAdFilm` 통과 여부 비교**

| | |
| --- | --- |
| 얻는 것 | 9/24 이후에도 소재가 나온다. 한국어 발음 문제 해소 가능성 |
| 잃는 것 | 없음 |
| 비용 | 비교 테스트 3편 ≈ $20 안팎 |
| 안 하면 | **9월 25일부터 영상 사업이 멈춘다** |

→ **이건 대안이 아니라 필수다.** 아래 두 안 중 무엇을 고르든 이건 한다.

---

### 안 2. 「포맷 카탈로그」 — CCFM 을 정면으로 받는다 ★ 권고
실사 UGC 한 종류에서 **포맷 축**을 만든다. `FILM_TONE` 상수 하나를 포맷별 프리셋으로 쪼갠다.

시작 포맷 4종 제안 (우리 서사 8단·소구 12칸은 그대로 얹힌다):

| 포맷 | 왜 | 규제 |
| --- | --- | --- |
| **실사 UGC형** (현재 것) | 전환율 제일 높음. 우리가 이미 규격을 갖고 있음 | 가상인물 표시 필요 |
| **원료·성분 3D형** | 건기식·뷰티에서 설명이 필요한 지점. AI 티가 강점이 됨 | 무관 |
| **제품 물성 ASMR형** | 체류시간. 소리 켜고 보게 만드는 유일한 포맷 | 무관 |
| **정보 그래픽형** (비교표·수치 중심) | 우리가 블로그에서 이미 잘하는 일. 편집만으로 됨 | 무관 |

| | |
| --- | --- |
| 얻는 것 | 같은 제품으로 4~12편 변주 → **A/B 테스트가 상품이 된다.** 컨펌 단계를 없앨 수 있어 납기가 줄고, 편차가 사라져 "균일한 퀄리티"를 약속할 수 있다. 비실사 3종은 규제·AI티 논쟁 밖 |
| 잃는 것 | 포맷마다 프롬프트 프리셋과 편집 템플릿을 새로 만들어야 함(포맷당 1~2일) |
| 왜 우리에게 유리한가 | CCFM 은 포맷이 있고 규격이 없다(수정 1회·컷 교체 불가). **우리는 소구 12칸·자막 실측·나레이션 밀도·whisper 검증까지 규격이 있다.** 포맷만 얹으면 같은 값에 품질이 위다 |

---

### 안 3. 「하이브리드 파이프라인」 — 툴을 실제로 섞어 짠다
사장님이 말씀하신 *"프롬프트와 툴을 잘 섞어 짜야"* 를 끝까지 가는 안.

블링크스튜디오가 17개 모델을 쓰는 이유가 이거다. 층마다 잘하는 모델이 다르다:

```
스틸 소스   gpt-image-2 / Nano Banana Pro / Midjourney   ← 인물·제품 룩을 먼저 고정
영상화      Kling 3.0 (인물·모션브러시) / Seedance 2.0 (멀티샷·실사합성) / Veo 3.1 (연속성)
음성        Kling O3 네이티브 (한국어) 또는 ElevenLabs
업스케일    Topaz Video AI   ← 어느 모델도 4K를 안 준다
편집·자막   우리 ffmpeg 규격 (그대로 유지)
```

핵심은 **"영상부터 만들지 않는다"** 는 것이다. 스틸을 먼저 고정하고 image-to-video 로
가면 인물 일관성이 붙는다. 우리는 지금 text-to-video 로 시작해서 `extensions` 로 버티는데,
그게 sora 에 묶인 이유이기도 하다. 우리 계정에 `gpt-image-2` 가 이미 있다.

| | |
| --- | --- |
| 얻는 것 | 품질 상한이 올라감. 특정 벤더 종속에서 벗어남 |
| 잃는 것 | 파이프라인이 복잡해지고 계정·과금처가 늘어남. 편당 원가도 오름 |
| 언제 | 안 1·2 를 끝낸 뒤. 지금 시작하면 마감을 못 지킨다 |
