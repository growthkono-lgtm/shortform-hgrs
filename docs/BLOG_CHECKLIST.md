## 왜 이 문서가 있나

자동화의 위험은 고장이 아니라 **조용한 고장**입니다. 매일 한 편이 나가는 시스템이
멈추면 아무 일도 안 일어난 것처럼 보입니다. 메일이 안 오는 것과 메일이 올 일이
없는 것이 화면에서 똑같이 생겼습니다.

그래서 점검 항목은 "돌고 있나" 가 아니라 **"돌았어야 하는데 안 돈 것이 있나"** 로
씁니다. 아래 다섯 층을 순서대로 봅니다 — 방아쇠 → 원고 → 규격 → 성과 → 돈.

---

## 1층. 방아쇠 — 누가 깨우나

| 확인 | 정상값 | 어긋나면 |
| --- | --- | --- |
| `cron.job` 에 `blog-*` 예약 | **7개, 전부 active** | 예약이 지워졌거나 꺼진 것. 다시 등록 |
| 지난 24시간 발사 기록 | 성공 14회 안팎 · 실패 0 | 실패가 쌓이면 인증(`blog_cron_secret`)이나 주소를 본다 |

방아쇠는 **Supabase 안**에 있습니다(pg_cron + pg_net). 맥도, 외부 서비스도 아닙니다.
하루 26회 — 아침 09:00~09:55(12회)에 원고를 몰아 만들고, 13:00~13:40(9회)에 못
끝낸 것을 마무리하고, 17:05·17:20 발행, 17:10 구독알림, 18:05·19:05 리포트.

> 🚨 **로그가 비었다고 고장이 아닙니다.** 예약이 없는 시간대에는 아무도 두드리지
> 않습니다. 09:55~13:00 사이가 조용한 것은 **설계대로**입니다.

## 2층. 오늘 회차 — 원고가 나왔나

| 확인 | 정상값 | 어긋나면 |
| --- | --- | --- |

## 3층. 규격 — 사장님이 요청하신 것이 지켜졌나

검사식(`lib/blog-audit.ts`)이 **발행 전에 물리적으로 막습니다.** 통과 못 하면
그 원고는 나가지 않습니다.

| 사장님 요청 | 기준 | 막나 |
| --- | --- | --- |
| 국내 레퍼런스만 | 인용 자료 **70% 이상 국내**, 본문에서 재생되는 건 **해외 0건** | ✅ |
| 시각물 3~4개 | 재생 자료 + 표 **4~9개** (링크 한 줄은 안 셈) | ✅ |
| 핵심 포인트 강조 | `:::point` 박스 **3~4개** + 굵게 **6~16곳** | ✅ |
| 대안·방법 → 문의 연결 | `:::do` 실행 블록 1개(3~5단계) + **바로 다음 문단에 서비스 링크** | ✅ |
| 출처·연도·기준 | 자료마다 4종 전부 | ✅ |
| 숫자 지어내기 금지 | 목록에 없는 자료·수치 인용 차단 | ✅ |
| 분량 | 유형별 3,200~6,500자 | ✅ |
| 대표·이사급 톤 / 어필 문맥 | 지시문에만 있음 | ❌ **사람 눈이 필요한 자리** |

마지막 줄이 이 시스템의 유일한 빈 칸입니다. 숫자로 못 세는 것이라 검사식이 못
막습니다. 발행된 실물을 사장님이 이따금 읽어 주셔야 하고, 거기서 나온 지적이
다음 검사식이 됩니다(08-15 검수에서 네 가지가 그렇게 코드가 됐습니다).

### 규격 미달이면 — 거르지 않고 채웁니다

```
패치 → 패치 → 전면 재집필 → 패치 → 전면 재집필 → 패치 → (여기서 사람)
```

울타리는 시도 횟수가 아니라 **시간(15시 컷오프)** 과 **돈(편당 $4)** 입니다.

## 4층. 성과 — 측정되고 있나

| 확인 | 어디에 쌓이나 | 비고 |
| --- | --- | --- |
| 키워드 검색량·CTR | `blog_keyword` · `blog_keyword_metric`(주차별 이력) | 네이버 검색광고 실측. 주 1회 `keyword-sync.mjs` |
| 구글 노출·클릭·순위 | `blog_search_daily` (18시 리포트가 매일 한 줄) | **08-16 신설.** 그 전에는 읽고 버렸다 |
| 조회수 | `blog_view` | 우리가 직접 셈, 봇 제외, 세션당 1회 |
| 네이버 노출·순위 | **없음** | 네이버는 외부에서 읽을 공개 API를 안 준다. 시크릿 창으로 직접 확인 |

> "노출·순위가 비었다" 에는 두 가지가 섞여 있습니다 — **아직 안 잡힌 것**과
> **못 읽는 것**. 어드민 상단에 노란 박스가 뜨면 후자입니다. 0 으로 채우지 않는
> 이유가 이것입니다.
